# Privacy statement

This statement covers the Microsoft 365 Copilot agents published by Veysel Alevcan: the agents listed in this repository's README, plus Copilot Security Advisor, Phishing Triage Analyst and Cyber Awareness Quiz Tutor.

- The agents are declarative agents that run inside Microsoft 365 Copilot in your organization's tenant. Microsoft processes prompts, responses and grounding data under your organization's Microsoft 365 agreement and the Microsoft Privacy Statement.
- The author does not operate any server, API, plugin or database for these agents and does not receive, store or see any prompt, response, file or user data.
- Knowledge sources are public web pages (for example Microsoft Learn, AWS and Google Cloud documentation, OWASP GenAI Security Project, MITRE ATLAS, NIST) or Copilot web search. The agents do not send your data to these sites.
- Do not paste personal data, secrets or credentials into the agents unless your organization's policy allows it.

Questions: open an issue in this repository.
